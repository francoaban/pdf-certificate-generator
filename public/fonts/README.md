# Fuentes

Las cuatro fuentes caligráficas se distribuyen con la **SIL Open Font License 1.1**.
Cada familia conserva su archivo de licencia y su atribución:

| Archivo | Familia | Licencia |
| ------- | ------- | -------- |
| `GreatVibes-Regular.ttf` | Great Vibes | `OFL-GreatVibes.txt` |
| `Sacramento-Regular.ttf` | Sacramento | `OFL-Sacramento.txt` |
| `PinyonScript-Regular.ttf` | Pinyon Script | `OFL-PinyonScript.txt` |
| `Parisienne-Regular.ttf` | Parisienne | `OFL-Parisienne.txt` |

Origen: [Google Fonts](https://github.com/google/fonts). Las fuentes se usan
únicamente para componer el nombre en los certificados y se incrustan en el PDF.
